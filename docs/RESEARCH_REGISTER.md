# Research register

**Access date:** 22 October 2026. External links and product/software documentation can change; re-check versions before hardware purchase or deployment. Sources below are chosen for official/vendor documentation or identifiable dataset repositories. This is not a claim that every candidate source or dataset has been downloaded or exhaustively audited.

## Research conclusions

1. The proposed hardware/dataflow is implementable with a simulation-first software structure; serial frames and app-level radio messages can be tested on PC before radios are bought.
2. The radio module/band mismatch must be fixed before physical procurement.
3. ESP-NOW requires explicit app-level delivery semantics if the base must prove that records were processed and saved.
4. The first useful ML result should be an image-only baseline with correct splits and limitations, not a “disease accuracy” claim built from synthetic images.
5. Real Pi/ESP32/radio/sensor tests are distinct acceptance stages, not an extension implied by passing the PC suite.
